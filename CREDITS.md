# Credits & Asset Licenses

## Original game assets

- Pixel art tiles, school library, towers, zombie frames, coins, heart and projectile visuals are generated at runtime from pixel matrices in `src/utils/PixelArtFactory.ts`.
- No third-party sprites, illustrations, sound recordings, or music tracks are bundled.
- Sound effects are synthesized using the browser Web Audio API (`src/systems/AudioManager.ts`).
- World palettes, tower marks, UI layout, game icon treatments and exported result-card PNG images are generated by original project code.
