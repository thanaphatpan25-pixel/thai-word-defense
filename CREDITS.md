# Credits & Asset Licenses

## Third-party pixel art

This game incorporates artwork from these CraftPix free asset packs:

- **Free Archer Towers Pixel Art for Tower Defense** — tower sprites and upgrade frames.
- **Free Fields Tileset Pixel Art for Tower Defense** — field terrain, path tiles, vegetation, fences, rocks, and decorative objects.
- **Free Urban Zombie Sprite Sheet Pixel Art Pack** — zombie character animation frames.

Official license terms: https://craftpix.net/file-licenses/

The supplied pack archives identify the CraftPix file-license page. The assets are used as part of the playable game and are not offered as standalone downloads. Original ZIP archives, PSD files, and unused source material are not included in this repository. The game's compiled atlas and composed battlefield are runtime resources only.

## Original project artwork

- The 754×464 battlefield is composed from the selected Fields Tileset to align with the existing 13×8 gameplay route.
- The school library landmark is rendered once in GameScene; the decorative menu no longer draws a second school structure.
- Tower/enemy role mappings, animation registration, and in-game labels are project code.
