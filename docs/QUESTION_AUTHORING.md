# คู่มือครู: เพิ่มและตรวจทานโจทย์ภาษาไทย

1. เลือกไฟล์ JSON ตามหมวดใน `src/data/questions/` แล้วเพิ่ม object ใหม่ใน array
2. ตั้ง `id` ไม่ซ้ำทั้งคลัง เช่น `spelling-031` และเลือก `difficulty` 1–3
3. เลือก `type` ให้สอดคล้องกับกิจกรรม: `multiple-choice`, `fill-blank`, `true-false`, `matching`, `order`
4. เขียนคำอธิบายสั้น ๆ ที่บอกเหตุผลหรือหลักภาษา
5. ถ้ายังไม่แน่ใจด้านหลักภาษา ให้เพิ่ม `todo` เพื่อเตือนให้ครูตรวจสอบ
6. รัน `npm run validate:questions` และ `npm test` ก่อนนำขึ้นเว็บ

สำหรับ `order` ให้ใส่คำตอบด้วย `|` เช่น `นักเรียน|อ่าน|หนังสือ` และใส่คำแต่ละส่วนใน `choices` ด้วย

## รายการตรวจทานก่อนใช้ในชั้นเรียน

- สะกดคำและคำตอบถูกต้องตามพจนานุกรม/หลักสูตรที่ใช้
- ตัวเลือกผิดไม่ควรมีคำตอบถูกซ้ำหรือเป็นคำตอบที่ถูกได้มากกว่าหนึ่งข้อ
- ประโยคตัวอย่างมีบริบทเหมาะสมกับ ป.4–ป.5
- คำอธิบายตรงกับเฉลย ไม่กำกวม และไม่ใช้ศัพท์ยากเกินวัย
- ข้ออ่านจับใจความให้คำตอบได้จากข้อความ ไม่ต้องเดาความรู้ภายนอก
- ครูตรวจ TODO ทุกข้อก่อนนำไปสอบ/เก็บคะแนนจริง
